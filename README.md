# Бот сертификатов Ember

Бот оформляет подарочные сертификаты по шаблонам ресторана и проверяет их при погашении.

## Первый запуск

1. Откройте файл `.env` (правой кнопкой → «Открыть с помощью» → «Блокнот») и вставьте токен от @BotFather после `BOT_TOKEN=`.
2. Дважды щёлкните `start_bot.bat`. Откроется чёрное окно — **не закрывайте его**, пока бот должен работать.
3. Напишите боту в Telegram `/start` — он покажет ваш Telegram ID.
4. Впишите этот ID в `.env` после `ADMIN_IDS=`, закройте окно бота и запустите `start_bot.bat` снова.
5. Снова `/start` — теперь вы администратор, появится меню.

**Перезапуск (например, после обновления)** — просто запустите `start_bot.bat` ещё раз. Новая копия сама закроет старую вместе с её окном и напишет «Предыдущая копия бота закрыта». Старая закрывается только если новая успешно подключилась к Telegram — с ошибкой в `.env` работающий бот не пострадает.

Если в окне появится «ВНИМАНИЕ: … бот запущен ещё где-то» — значит, бот работает на другом компьютере (или запущен не из этой папки). Закройте ту копию.

## Создание сертификата (сотрудник или администратор)

🎟 **Создать сертификат** → бот по очереди спросит:
1. **Номер** — ровно 8 цифр (например, `00482915`). Номер должен быть новым: повторить существующий бот не даст.
2. **Сумму** в рублях.
3. **Кто выдал** — например, `Иванова А. С.` (до 30 символов). Печатается на обороте в строке «Управляющий». Бот запоминает последнее имя и предлагает его кнопкой; можно выбрать «Без имени».

Бот пришлёт обе стороны сертификата и кнопку **«📄 PDF для печати»** — PDF из двух страниц (лицевая сторона и оборот) размером 210×99 мм для двусторонней печати.

Быстрее, одной строкой: `/new 00482915 5000 Иванова А. С.`

## Проверка и погашение

Сотрудник просто отправляет номер (можно с пробелами, дефисом или знаком «№»):
- ✅ «Сертификат действителен» — бот **сразу** отмечает его использованным и показывает сумму.
- ⛔️ «Уже использован» — с датой и тем, кто погасил.
- ❌ «Не найден» — номер введён неверно или такого сертификата нет.

## Только для администратора

Администраторов может быть сколько угодно, права у всех одинаковые.
- **Главные** — их ID записаны в `.env` в строке `ADMIN_IDS=` (несколько — через запятую). Убрать их из бота нельзя, только в файле.
- **Остальные** — назначаются прямо в боте, без правки файлов и перезапуска.

- 📋 **Все сертификаты** → статусы, сумма действующих, кнопка «📥 Скачать список (Excel)».
- 👥 **Сотрудники** → вся команда: администраторы и сотрудники. Кнопки «⭐ В админы», «⬇️ Снять админа», «✖️ Удалить».
  Чтобы добавить человека, пусть откроет бота и нажмёт «Старт» — всем администраторам придёт запрос с кнопками «✅ Сотрудник» и «⭐ Администратор».
- `/addadmin ID Имя` — назначить администратора, `/deladmin ID` — снять права (человек останется сотрудником).
- `/restore 00482915` — вернуть сертификат в действующие, если его погасили по ошибке.
- `/delete 00482915` — удалить сертификат (например, ошиблись в номере или сумме). Бот попросит подтверждение.

## Файлы

| Файл | Что это |
|---|---|
| `data/certificates.db` | **База всех сертификатов и сотрудников. Делайте резервную копию!** |
| `assets/front.png`, `assets/back.png` | Шаблоны лицевой стороны и оборота. Можно заменить на версию лучшего качества с теми же пропорциями. |
| `assets/fonts/GolosText-wght.ttf` | Шрифт Golos Text (бесплатный, лицензия OFL — `assets/fonts/OFL.txt`). Им пишутся сумма, номер и имя. |
| `assets/fonts/regular.ttf` | (необязательно) Фирменный шрифт — если положить его сюда, бот будет писать им вместо Golos. |
| `.env.example` | Образец настроек без секретов |
| `.gitignore` | Список того, что нельзя выкладывать на GitHub (`.env`, `data/`) |
| `.env` | Токен и ID администраторов. Никому не пересылайте — по токену можно управлять ботом. |
| `bot.py` | Логика бота |
| `render.py` | Где на шаблонах пишутся сумма, номер и имя |
| `single_instance.py` | Закрывает старую копию бота при новом запуске |
| `data/bot.pid` | Номер процесса работающей копии (служебный) |

## Загрузка на GitHub и хостинг

**На GitHub загружаются все файлы, КРОМЕ:** `.env` (там токен!), папки `data` (база с данными клиентов) и `__pycache__`.

1. github.com → **New repository** → имя, например `ember-bot` → **Private** → **Create repository**.
2. На странице репозитория — ссылка **«uploading an existing file»** → перетащить файлы и папку `assets` → **Commit changes**.
3. На хостинге: «Git URL репозитория» — `https://github.com/ЛОГИН/ember-bot.git`, ветка `main`.
4. В настройках хостинга (переменные окружения) задать:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — ID главных администраторов через запятую;
   - `TIMEZONE` — `Europe/Moscow`;
   - `DATA_DIR` — путь к **постоянному** диску/тому, если хостинг его даёт. Иначе база может стираться при перезапуске или обновлении.
5. Команда запуска: `python bot.py` (зависимости — в `requirements.txt`).
6. Когда бот заработал на хостинге — **закройте копию на компьютере**, иначе будет ошибка Conflict.

База на хостинге начнётся с нуля: сертификаты с компьютера туда сами не переедут.

## Важно

- Бот работает, только пока открыто окно `start_bot.bat` и включён компьютер. Чтобы работал круглосуточно — перенесите папку на сервер (VPS).
- Шаблоны сейчас 1024×484 пикселя — для печати бот увеличивает их вдвое, но если у дизайнера есть исходники в большем размере (или PDF), качество печати будет лучше.
